2. Descriptive Statistics (always sort first)

x̄ = (Σ xi) / n   |   Sxx = Σ(xi − x̄)² = Σ xi² − (Σ xi)² / n
s² = Sxx / (n − 1)   |   s = √s²     (sample; use n−1, not n)
  • Median: middle value after sorting. Even n → average the two middle values.
  • Q1 / Q3: medians of the lower / upper half. Even n: split into two equal halves, then take those medians. Review n=20 → Q1 = 6.
  • α% trimmed mean: drop α% of observations from each tail, then average the rest. 10% trim, n=10 → drop 1 from each end (10%×10=1).
  • Histogram bins: # bins ≈ √n. Interval notation: [a, b] inclusive; (a, b] means a < x ≤ b.
If they give Σx and Σx², do not re-sum the list. Use Sxx = Σx² − (Σx)²/n.

3. Combinatorics — order vs not, repeats vs not

SituationFormulaWhen
Permutation P(n,k)n! / (n−k)! = n(n−1)…(n−k+1)Order matters, no repeats (passwords with unique letters, lined-up crews)
Combination C(n,k)n! / [k!(n−k)!] = P(n,k)/k!Order does not matter (committees, choosing which rebars)
With replacement / repeats OKnkk slots, n options each (4-letter words, letters may repeat)
5-letter words, no repeated letters, from 26: P(26,5) = 26×25×24×23×22 = 7,893,600
4-letter words, repeats allowed: 264 = 456,976
Exam test: “same items in different order count as different” → permutation or nk. “Unordered / just a set of objects” → combination.

4. Probability Rules

0 ≤ P(A) ≤ 1,   P(S)=1,   P(Ac)=1−P(A)
P(A ∪ B) = P(A)+P(B)−P(A ∩ B)
A, B mutually exclusive ⇒ P(A ∩ B)=0 ⇒ P(A ∪ B)=P(A)+P(B)

Conditional · Joint · Marginal

P(A | B) = P(A ∩ B) / P(B) = [P(B|A) P(A)] / P(B)
conditional = joint / marginal    rearrange: P(A ∩ B) = P(A|B)P(B) = P(B|A)P(A)

Law of Total Probability

P(B) = Σi P(B | Ai) P(Ai)
Ai must be mutually exclusive AND collectively exhaustive (a partition of S)

Bayes’ Theorem (write this from memory — it is a recall question)

P(Ai | B) = P(B | Ai) P(Ai)  /  Σj P(B | Aj) P(Aj)
= P(Ai ∩ B) / P(B)    “flip” from cause→effect to effect→cause

Independence

A, B independent ⇔ P(A|B)=P(A) ⇔ P(A ∩ B)=P(A)P(B)
Mutually independent A1…Ak: P(all occur) = Π P(Ai)
Do not assume independence. Prove it with P(A∩B)=P(A)P(B), or the problem must say “independent / random / with replacement / large population.”

5. Discrete RVs — pmf, CDF, mean, variance

pmf: p(x)=P(X=x),   0 ≤ p(x) ≤ 1,   Σ p(x) = 1
CDF: F(x)=P(X ≤ x)= Σi≤x p(i)   (right-continuous step function)
P(X > a) = 1 − F(a)  |  P(X ≥ k) = 1 − F(k−1)  |  P(a ≤ X ≤ b)=F(b)−F(a−1)
E[X] = μ = Σ x p(x)     E[h(X)] = Σ h(x) p(x)
V(X) = σ² = E[(X−μ)²] = E[X²] − μ²     SD(X)=σ=√V(X)
E[X²] = Σ x² p(x)    (not (E[X])²)
When is E[h(X)] = h(E[X])? Only if h is linear: h(x) = a + bx.
Then E[a+bX]=a+bμ and V(a+bX)=b² V(X), SD=|b|σ.
If h is quadratic / 1/X / etc., you must compute Σ h(x)p(x). Do not plug μ into h.
Worked nonlinear: want E[2X²+3] and V[2X²+3]. First get E[X²]=V(X)+μ², then E[2X²+3]=2E[X²]+3. For the variance, 2X²+3 is not linear in X, so V(2X²+3)=4 V(X²), and V(X²)=E[X⁴]−(E[X²])². Compute E[X⁴]=Σ x⁴ p(x) from the pmf. Shortcut V(aY+b)=a²V(Y) is OK after setting Y=X².

6. Binomial vs Hypergeometric

Binomial X ~ Bin(n, p) Hypergeometric X ~ Hyp(N, M, n)
Story # successes in n independent Bernoulli trials; p constant # successes in a sample of n drawn without replacement from finite N that has M successes
pmf P(X=x) = C(n,x) px (1−p)n−x P(X=x) = [C(M,x) C(N−M, n−x)] / C(N,n)
Mean μ = np μ = n (M/N) = np with p=M/N
Variance σ² = np(1−p) σ² = np(1−p)·[(N−n)/(N−1)]   FPC
Use if with replacement, or N huge so p barely changes, or trials independent finite population, without replacement, n not tiny vs N
Support: binomial x=0,1,…,n. Hypergeometric max(0, n−(N−M)) ≤ x ≤ min(n, M).

Multivariate hypergeometric (several types)

P(k1,k2,…,km) = [ C(N1,k1) C(N2,k2) ⋯ C(Nm,km) ] / C(N, n)
N = Σ Ni,   n = Σ ki. Classic: 5+5+5 rebars, grab 6, want 2 of each: C(5,2)³ / C(15,6) = 1000/5005 = 0.1998
Flu example (15 students: 4 sen, 5 jun, 6 frosh; pick 3):
P(exactly 2 frosh)= C(6,2)C(9,1)/C(15,3)=135/455=0.2967
P(all 3 same class)= [C(4,3)+C(5,3)+C(6,3)] / C(15,3)=34/455=0.0747
P(one of each)= C(4,1)C(5,1)C(6,1)/C(15,3)=120/455=0.2637

7. Joint RVs — independence check

Joint pmf p(s,t)=P(S=s, T=t). Marginals: pS(s)=Σt p(s,t), pT(t)=Σs p(s,t).
Independent RVs ⇔ p(s,t) = pS(s) pT(t) for every pair (s,t).
One counterexample kills independence. Review Ex. 3: P(S=0)=0.25, P(T=0)=0.5, product=0.125, but P(S=0,T=0)=0.25 ≠ 0.125 → dependent. Matching marginals is not enough. Zeros in the joint table while both marginals are positive also scream dependence.

8. Bayes trees (do this on every word problem)

  1. Define events. First branches = partition Ai with P(Ai).
  2. Second branches = P(B|Ai) and P(Bc|Ai).
  3. Joint on each leaf: P(Ai ∩ B)=P(Ai)P(B|Ai).
  4. P(B)=sum of B-leaf joints. Then P(Ai|B)=jointi / P(B).
Austine energy: P(A1,A2,A3)=(0.40, 0.35, 0.25), P(B|A)=(0.30, 0.60, 0.50)
Joints: 0.12, 0.21, 0.125 → P(B)=0.455
P(A2 ∩ B)=0.21  |  P(A1|B)=0.12/0.455=0.2637  |  P(A2|B)=0.4615  |  P(A3|B)=0.2747
Upgrade/stable Bayes (sample exam): P(U)=0.20, P(S|U)=0.90, and P(S) from the table (450/525). Then P(U|S)= (0.90)(0.20)/P(S)=0.21. Do not invent P(S) if the table already gives it.

9. Filling a contingency table

  1. Write every known count. Translate each sentence into an equation.
  2. “One-third of all dams are rural” → Rural = (1/3) Total, so Urban = (2/3) Total → Total = (3/2)×Urban.
  3. Row/column totals are gold. Check that every row and column adds.
  4. Conditional from a table: P(unstable | rural) = (# rural and unstable) / (# rural).
Sample exam rural row: 100, 20, 50, 5 (old-stable, old-unstable, new-stable, new-unstable). P(unstable|rural)=25/175=0.1429.

10. Estimating Bin(n, p) from data

If yearly counts of “contaminated lakes” look like X ~ Bin(n,p) with n, p unknown:

x̄ ≈ np     s² ≈ np(1−p)
p̂ = 1 − s² / x̄     n̂ = x̄ / p̂
Sample: x̄=89.7, s=9.044, s²=81.79 → p̂=1−81.79/89.7=0.08819 → n̂=89.7/0.08819≈1017.
Extra-credit attack on binomial: lakes are not independent (spatial clusters of mercury); population of lakes is finite (hypergeometric); p may change year to year; n may not be constant; sampling design may not be simple random trials.

12. Calculator & presentation

  • nCr: combinations. nPr: permutations. Don’t mix them.
  • Carry extra digits; round only the boxed answer (3–4 significant figures unless they want a percent).
  • Percents vs decimals: 21% = 0.21. Stay consistent inside a calculation.
  • Write the distribution name and parameters before plugging in numbers.
  • If sampling without replacement from a listed finite set, it is hypergeometric / multivariate hypergeometric — not binomial — unless you explicitly approximate.
